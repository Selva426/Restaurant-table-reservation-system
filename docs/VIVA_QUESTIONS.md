# Viva Preparation – Restaurant Table Reservation System

1. **What is Django?** A Python web framework that provides URL routing, views, templates, authentication and database tools.
2. **What is a Django model?** A Python class that describes a database table and its fields.
3. **What is a migration?** A versioned instruction Django uses to create or modify database schema.
4. **What is CRUD?** Create, Read, Update and Delete.
5. **Why use MySQL?** It is a relational database suitable for structured records and relationships.
6. **What is a foreign key?** A field that links a record to a row in another table.
7. **Why is login_required used?** It restricts a view to authenticated users.
8. **How is reservation ownership checked?** Views query by both reservation ID and the currently logged-in customer.
9. **What is form validation?** Checking submitted values before saving them.
10. **Why validate on the server as well as JavaScript?** Browser-side checks can be bypassed, so server-side validation is essential.
11. **What is the purpose of search and filters?** To find relevant reservation records quickly.
12. **What is the Django admin?** A built-in interface for authorized staff to manage application data.
13. **What is the purpose of Git?** It tracks changes to source code.
14. **What is GitHub?** A hosting platform for Git repositories and project collaboration.
15. **What is the difference between authentication and authorization?** Authentication verifies identity; authorization determines what that identity is allowed to access.
